**Концепция**- это проект попытка проработать концепцию разработки электронных систем с использованием LLM (нейросетей). Для этого заложеный следующие концепции:
- Чертеж должен стать кодом
- CAD должен дать удобные инструменты доступа к LLM,для создания кода и передачи задач (промтов), для визуализации полученного кода в человеко-понятный вид.
- CAD становится инструментом проверки целостности и не противоречивости кода
- важная проблема - верификация проекта. Пока я вижи два пути: оценка человеком (специалистом) через визуальные представления, и оценка 
- человек задает направление движения (разработки) и определяет следующий шаг

Текущее состояние:
- LLM через чат в браузере
- базовые стредства визуализации
- базовые правила для создания проекта (промты)

**План развития по модулям**

1. Модуль компонентов  
Назначение: Отображение информации о компоненте, редактирование полей, верификация данных о компоненте, подготовка файлов компонента к использованию

Дополнить:

- проверка уникальности id в рамках проекта
- экспорт списка занятых id в рамках проекта
- Отображение SVG символа с сопоставлением портов и номеров пинов из файла symbols.json. 
- Проверка целостности связки symbols.json, name.svg, name.cfcomp
- изображение корпуса в svg (или footprint?)
	
2. Модуль BOM (Спецификация)  
Назначение: список компонентов проекта для последующего формировании Цепей, список для закупки. Оценка стоимости копонентов.

Дополнить

- поле стоимость 
- итоговая стоимость компонентов
- назначение реального компонента руками и через API (KiCAD)

3. Модуль Nets (Связи, Цепи)

Назначение: формирования, корректировка, валидация, верификация цепей (связей) внутри проекта

Дополнить:

- количество пинов в цепи не расчитывается -- исправить
- проработать терминологию - надписи на кнопках и в таблице
- отображение матрицы - проработать визуальное объединение в компаненты
- отображение матрицы по страницам (ограничение в ширину, можно использовать метку "labelMode" для формирования переносов)

4. Модуль Схема

Назначение: Визуальная оценка правильности подключения и целостности проекта.

Доработать:

- расположение надписей и подписей - доработать
