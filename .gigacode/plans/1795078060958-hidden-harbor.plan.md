# План исправления: таблицы не отображаются / слишком узкие

## Проблема (подтверждена по скриншотам)

Таблицы **отрисовываются**, но **крайне узкие по высоте** — видна лишь тонкая полоска сетки. Данные загружены (48 портов для STM32), колонки настроены, но VBox не даёт таблицам расти.

**Корень проблемы:** В `createRoot()` строка `HBox.setHgrow(componentTable, Priority.ALWAYS)` **не работает** — `componentTable` не прямой дочерний узел HBox, он внутри `leftPanel`. Поэтому `rightPanel` не получает достаточно пространства по ширине, и TabPane внутри него не может развернуться по высоте.

**Вторичная проблема:** формы свойств разделены на `mainProp*` и `extraProp*`, но сами таблицы портов и свойств используют inline anonymous TableCell — это работает корректно.

## Решение

### Единственное критичное изменение: `HBox.setHgrow(rightPanel, Priority.ALWAYS)`

В `createRoot()` заменить:
```kotlin
// БЫЛО (не работает — componentTable не прямой дочерний HBox):
root.center = HBox(0.0, leftPanel, rightPanel).apply {
    HBox.setHgrow(componentTable, Priority.ALWAYS)
}
```

На:
```kotlin
// СТАЛО (rightPanel — прямой дочерний HBox):
root.center = HBox(0.0, leftPanel, rightPanel).apply {
    HBox.setHgrow(rightPanel, Priority.ALWAYS)
}
```

**Почему это решает проблему:**
- `rightPanel` — прямой дочерний HBox, поэтому `setHgrow` на нём сработает
- `rightPanel` начнёт занимать всё доступное пространство по ширине
- TabPane внутри `rightPanel` (через VBox с `setVgrow`) получит достаточно пространства и развернётся по высоте
- Таблицы внутри TabPane (через `VBox.setVgrow(tableView, Priority.ALWAYS)`) тоже развернутся

### Код уже содержит все остальные исправления

- Inline anonymous `object : TableCell<Port, String>()` — уже реализовано ✅
- Разделённые формы `mainProp*` / `extraProp*` — уже реализовано ✅
- Отдельные обработчики `addMainPropertyRow()` / `addExtraPropertyRow()` — уже реализовано ✅
