## Проверка соответствия последним изменениям

### SchematicDocument.kt — удалены WireConnection/WireBendPoint
- Тесты не используют `wires`, `WireConnection`, `WireBendPoint`
- Все тесты используют только `SchematicNode` и `SchematicDocument(nodes = ...)`

### BomDocument.kt — bomnetId default = "", добавлен description
- Тесты не передают `bomnetId` явно — используется default значение
- Поле `description` не используется в тестах, но имеет default

### ComponentRepository.kt — atomic save-then-delete, loadComponentById
- Тесты вызывают `saveComponent()` с именованными параметрами, совпадают с сигнатурой
- `loadComponentById()` не используется в тестах напрямую

### BomRepository.kt — loadRows() с кэшем
- `loadRows()` не вызывается в тестах, используется `load()` и `initFromComponents()`
