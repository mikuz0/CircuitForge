## 2. [MAJOR] ComponentRepository.kt — loadComponentById() загружает всё в память

**Файл:** `src/main/kotlin/ru/circuitforge/project/ComponentRepository.kt:242-258`

**Проблема:** `stream.toList()` загружает все файлы в память. При 500 компонентах — 500 десериализаций сразу.

**Исправление — ленивый поиск через sequence:**
```kotlin
fun loadComponentById(projectDir: Path, componentId: String): Component? {
    val componentsDir = projectDir.resolve("components")
    if (!Files.exists(componentsDir)) return null
    return try {
        sequence {
            Files.list(componentsDir).use { stream ->
                stream.forEach { path ->
                    if (path.fileName.toString().endsWith(CFCOMP_EXT)) {
                        runCatching { load(path) }.getOrNull()
                            ?.takeIf { it.id == componentId }
                            ?.let { yield(it) }
                    }
                }
            }
        }.firstOrNull()
    } catch (e: Exception) {
        logger.error("Failed to find component by id: $componentId", e)
        null
    }
}
```

## 4. [MAJOR] BomRepository.kt — loadRows() O(N×M) сканирование

**Файл:** `src/main/kotlin/ru/circuitforge/project/BomRepository.kt:103-125`

**Проблема:** Для каждого BomItem с пустым `slug` сканируется вся папка components. При 100 BOM-строках и 100 компонентах — 10 000 итераций.

**Исправление — загрузить компоненты один раз в кэш:**
```kotlin
fun loadRows(paths: ProjectPaths): List<BomRow> {
    val bomDoc = load(paths)
    
    // Кэш: id -> Component
    val componentCache = mutableMapOf<String, Component>()
    val componentsDir = paths.componentsDir
    if (Files.exists(componentsDir)) {
        try {
            Files.list(componentsDir).use { stream ->
                stream.filter { it.fileName.toString().endsWith(CFCOMP_EXT) }
                    .forEach { path ->
                        runCatching { load(path) }.getOrNull()?.let { componentCache[it.id] = it }
                    }
        } catch (e: Exception) {
            logger.warn("Failed to scan components dir for cache: ${paths.componentsDir}", e)
        }
    }
    
    val rows = mutableListOf<BomRow>()
    bomDoc.items.forEach { item ->
        val comp = componentCache[item.componentId]
        val compName = comp?.name ?: "<not found>"
        val prefix = comp?.refPrefix ?: "?"
        val slug = item.componentSlug.ifBlank {
            comp?.let { 
                paths.projectDir.resolve("components").listFiles { f -> 
                    f.fileName.toString().removeSuffix(CFCOMP_EXT) == generateSlug(it.name) 
                }?.firstOrNull()?.fileName?.toString()?.removeSuffix(CFCOMP_EXT) 
            } ?: ""
        }
        
        rows.add(BomRow(
            bomnetId = item.bomnetId,
            number = item.number,
            refDes = item.refDes,
            componentId = item.componentId,
            componentSlug = slug,
            componentName = compName,
            comment = item.comment,
            refPrefix = prefix
        ))
    }
    return rows
}
```

## 5. [MAJOR] ComponentsWindow.kt — Дублирование cell factory

**Файл:** `src/main/kotlin/ru/circuitforge/ui/components/ComponentsWindow.kt`

**Проблема:** 6 копипаст cell factory для редактируемых ячеек (~30 строк каждая).

**Исправление — extension-функция в отдельном файле:**

Создать `src/main/kotlin/ru/circuitforge/ui/common/EditableTableCell.kt`:
```kotlin
package ru.circuitforge.ui.common

import javafx.scene.control.TableCell
import javafx.scene.control.TextField
import javafx.util.Callback
import javafx.scene.control.TableColumn

/**
 * Создаёт редактируемую ячейку с TextField для TableColumn<T, String>.
 * Автокоммит при Enter или потере фокуса.
 */
fun <T> TableColumn<T, String>.setupEditableCell() {
    cellFactory = Callback { _: TableColumn<T, String> ->
        object : TableCell<T, String>() {
            private val tf = TextField()
            init {
                tf.setOnAction { commitEdit(tf.text) }
                tf.focusedProperty().addListener { _, _, focused ->
                    if (!focused) commitEdit(tf.text)
                }
            }
            override fun startEdit() {
                super.startEdit()
                tf.text = item ?: ""
                graphic = tf
                text = null
                tf.requestFocus()
                tf.selectAll()
            }
            override fun cancelEdit() {
                super.cancelEdit()
                text = item
                graphic = null
            }
            override fun updateItem(item: String?, empty: Boolean) {
                super.updateItem(item, empty)
                if (empty || item == null) {
                    text = null
                    graphic = null
                } else if (isEditing) {
                    tf.text = item
                    graphic = tf
                    text = null
                } else {
                    text = item
                    graphic = null
                }
            }
        }
    }
}
```

Заменить все 6 cell factory в `ComponentsWindow.kt` на:
```kotlin
pinCol.setupEditableCell()
nameCol.setupEditableCell()
descCol.setupEditableCell()
```
