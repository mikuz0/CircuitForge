# Исправление: SVG символы не отображаются (белые области)

## Диагностика

**Две критические ошибки из логов:**

1. **Missing xerces** — `SAX2 driver class org.apache.xerces.parsers.SAXParser not found`
   - SvgParser использует `SAXSVGDocumentFactory("org.apache.xerces.parsers.SAXParser")`
   - Но xerces не в зависимостях

2. **ClassCastException** — `kotlin.Unit cannot be cast to SwingNode`
   - `SwingUtilities.invokeAndWait { ... }` возвращает `Unit` (void в Java)
   - Пытаемся сделать `as SwingNode` — крашится

## Исправления

### 1. Добавить xerces dependency

**Файл:** `build.gradle.kts`

```kotlin
// Xerces — SAX parser для Batik
implementation("org.apache.xmlgraphics:batik-all:1.17")
implementation("xerces:xercesImpl:2.12.2")
```

### 2. Исправить ComponentRenderer — корректно создать SwingNode

**Файл:** `src/main/kotlin/ru/circuitforge/ui/schematic/ComponentRenderer.kt`

`SwingUtilities.invokeAndWait` возвращает `Unit`. Нужно использовать другой подход:

```kotlin
private fun drawSvgSymbol(group: Group, row: BomRow, comp: Component, symbolType: String) {
    val registry = SymbolRegistry.getInstance()
    val originalSymbolPane = registry.getSymbol(symbolType) as Pane
    
    val swingWidth = originalSymbolPane.prefWidth.takeIf { it > 0.0 } ?: 100.0
    val swingHeight = originalSymbolPane.prefHeight.takeIf { it > 0.0 } ?: 80.0
    
    // Создаём SwingNode корректно
    val swingNode = createSwingNodeWithSvg(swingWidth, swingHeight)
    
    group.children.add(swingNode)
    // ... labels
}

private fun createSwingNodeWithSvg(width: Double, height: Double): javafx.embed.swing.SwingNode {
    var result: javafx.embed.swing.SwingNode? = null
    val error = arrayOf<Throwable?>(null)
    
    SwingUtilities.invokeAndWait {
        try {
            val canvas = org.apache.batik.swing.JSVGCanvas().apply {
                setDocumentState(org.apache.batik.swing.JSVGCanvas.ALWAYS_DYNAMIC)
                // Создаём пустой SVG или загружаем из ресурсов
                val emptyDoc = org.apache.batik.anim.dom.SVGDOMImplementation.getDOMImplementation()
                    .createDocument("http://www.w3.org/2000/svg", "svg", null)
                        as org.w3c.dom.svg.SVGDocument
                setSVGDocument(emptyDoc)
            }
            
            result = javafx.embed.swing.SwingNode().apply {
                content = canvas
            }
        } catch (e: Exception) {
            error[0] = e
        }
    }
    
    if (error[0] != null) {
        throw RuntimeException("Failed to create SwingNode", error[0])
    }
    
    return result!!
}
```

### 3. Упростить SvgParser — не использовать xerces hardcoded

**Файл:** `src/main/kotlin/ru/circuitforge/ui/schematic/symbols/SvgParser.kt`

Убрать hardcoded parser class:

```kotlin
// Было:
private val svgDocumentFactory = SAXSVGDocumentFactory("org.apache.xerces.parsers.SAXParser")

// Стало:
private val svgDocumentFactory = SAXSVGDocumentFactory()
```

### 4. Добавить fallback — если Batik не работает, использовать простой Pane

**Файл:** `src/main/kotlin/ru/circuitforge/ui/schematic/ComponentRenderer.kt`

```kotlin
private fun createSwingNodeWithSvg(width: Double, height: Double): javafx.embed.swing.SwingNode {
    return try {
        // Пытаемся создать с Batik
        val swingNode = createSwingNodeWithBatik(width, height)
        swingNode
    } catch (e: Exception) {
        logger.error("Failed to create SwingNode with Batik: ${e.message}", e)
        // Fallback: простой Pane с текстом
        javafx.scene.layout.Pane().apply {
            prefWidth = width
            prefHeight = height
            style = "-fx-background-color: lightgray; -fx-border-color: black;"
        }
    }
}
```
