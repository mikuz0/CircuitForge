# План: Обновление тестов для ProjectPaths

## Контекст

Основной рефакторинг уже выполнен:
- `Project` и `ProjectInfo` имеют `machineName` ✓
- `ProjectPaths` существует с правильными путями (`$machineName.bom.json` и т.д.) ✓
- `ProjectRepository.create()` создаёт папки с `machineName` ✓
- `BomRepository`, `NetRepository`, `SchematicRepository` принимают `ProjectPaths` ✓
- Все окна (BomWindow, NetWindow, SchematicWindow, ComponentsWindow) загружают `ProjectPaths` internally ✓

**Проблема:** Тесты вызывают репозитории напрямую с `Path`, а не с `ProjectPaths`. Нужно обновить все тесты.
