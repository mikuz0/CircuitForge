## BUG FIX: AddConnectionDialog не видит BOM

**Симптом:** При нажатии "Добавить соединение" в Nets появляется ошибка "BOM пуст. Сначала создайте BOM в редакторе."

**Корневая причина:** В `AddConnectionDialog.loadData()` создаётся `ProjectPaths` с пустым `machineName`:
```kotlin
val paths = ProjectPaths(projectDir, "")  // ← machineName = ""
```
Из-за этого `paths.bom` возвращает путь `.bom.json` вместо `proba.bom.json`.

**Решение:** Передавать `ProjectPaths` из `NetWindow` (где он уже корректно создан) вместо `Path`.

### Изменяемые файлы

#### 1. `src/main/kotlin/ru/circuitforge/ui/nets/AddConnectionDialog.kt`

Изменить конструктор:
```kotlin
// Было:
class AddConnectionDialog(
    ownerStage: Stage,
    private val projectDir: Path,
    ...
)

// Стало:
class AddConnectionDialog(
    ownerStage: Stage,
    private val projectPaths: ProjectPaths,
    ...
)
```

Изменить `loadData()`:
```kotlin
// Было:
val paths = ProjectPaths(projectDir, "")
val rows = BomRepository.loadRows(paths)

// Стало:
val rows = BomRepository.loadRows(projectPaths)
```

Изменить `loadComponentById` вызовы:
```kotlin
// Было:
ComponentRepository.loadComponentById(projectDir, row.componentId)

// Стало:
ComponentRepository.loadComponentById(projectPaths.projectDir, row.componentId)
```

#### 2. `src/main/kotlin/ru/circuitforge/ui/nets/NetWindow.kt`

Изменить вызов `AddConnectionDialog`:
```kotlin
// Было:
AddConnectionDialog(
    ownerStage = stage,
    projectDir = paths.projectDir,
    ...
)

// Стало:
AddConnectionDialog(
    ownerStage = stage,
    projectPaths = paths,
    ...
)
```

### Верификация

1. Открыть проект с BOM
2. Выбрать цепь → "Добавить соединение"
3. Диалог должен показать строки BOM (не ошибку "BOM пуст")
4. Выбрать компонент и пин → "Добавить"
5. Соединение добавлено, nets.json сохранён
