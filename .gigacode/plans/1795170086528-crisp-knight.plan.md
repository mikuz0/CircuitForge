# План: Исправление отсутствия связей на схеме

## Проблема решена ✅

При активации пинов на схеме **линии теперь рисуются** для всех цепей.

---

## Выполненные исправления

### 1. `drawPortConnections()` — убрана зависимость от BOM

**Файл:** `src/main/kotlin/ru/circuitforge/ui/schematic/SchematicWindow.kt`

**Изменения:**
- Убран поиск по `bomRows` при сборе координат пина
- Рисование линий для **всех найденных** координат (≥ 2 точек)
- Если хотя бы один пин не найден — линии рисуются для остальных

**Было:**
```kotlin
net.connections.forEach { conn ->
    val row = bomRows.find { it.refDes == conn.refDes } ?: return@forEach  // ← ПРОПУСК
    val coords = getPinCoordinates(conn.refDes, conn.pinNumber)
    ...
}
if (portCoords.isEmpty()) return@forEach  // ← ВСЯ ЦЕПЬ ПРОПУСКАЕТСЯ
```

**Стало:**
```kotlin
net.connections.forEach { conn ->
    val coords = getPinCoordinates(conn.refDes, conn.pinNumber)
    if (coords != null) {
        portCoords.add(...)
    }
}
if (portCoords.size < 2) return@forEach  // ← Рисуем для найденных
```

### 2. `getPinCoordinates()` — убрано двойное смещение

**Было:**
```kotlin
return Pair(
    circle.layoutXProperty().value + portPane.layoutXProperty().value,
    circle.layoutYProperty().value + portPane.layoutYProperty().value
)
```

**Стало:**
```kotlin
return Pair(circle.layoutX, circle.layoutY)
```

### 3. `drawNetLabelsForActivePorts()` — метки для найденных пинов

**Изменения:**
- Метки рисуются для **всех найденных** пинов
- Если хотя бы один пин не найден — метки рисуются для остальных
