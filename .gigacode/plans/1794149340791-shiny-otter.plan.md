# Исправление: пустые connections в nets.json

## Причина
kotlinx.serialization не сериализует поля с дефолтными значениями, если они пусты. `connections = emptyList()` не записывается в JSON.

## Исправление в NetDocument.kt

**Было:**
```kotlin
@Serializable
data class Net(
    val name: String = "",
    val connections: List<NetConnection> = emptyList()
)
```

**Стало:**
```kotlin
@Serializable
data class Net(
    val name: String = "",
    @EncodeDefault(ALWAYS)
    val connections: List<NetConnection> = emptyList()
)
```

## Команда для проверки

```bash
./gradlew clean build && ./gradlew run
```

1. Создать цепь → проверить, что в nets.json есть `"connections":[]`
2. Добавить соединение → проверить, что connections заполняется
3. Перезапустить → соединения должны загрузиться
