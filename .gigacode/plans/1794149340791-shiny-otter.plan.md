# План: Contract Tests для репозиториев CircuitForge

## 1. Изменения в build.gradle.kts

**Строка `dependencies {}` — добавить после существующих:**
```kotlin
testImplementation("org.junit.jupiter:junit-jupiter:5.10.2")
testImplementation("org.jetbrains.kotlin:kotlin-test-junit5")
testRuntimeOnly("org.junit.jupiter:junit-jupiter-engine:5.10.2")
```

**В конец файла — добавить блок:**
```kotlin
tasks.test {
    useJUnitPlatform()
}
```

## 2. Новые файлы тестов

### src/test/kotlin/ru/circuitforge/project/ComponentRepositoryTest.kt
- `testCreateComponent` — создаёт проект в TempDir, вызывает `createComponent()`, проверяет наличие `<slug>.cfcomp`
- `testLoadComponent` — создаёт компонент, загружает через `loadComponent()`, проверяет name/refPrefix/ports
- `testUniqueNameValidation` — создаёт компонент, затем `saveComponent()` с тем же name — ожидает `IllegalArgumentException`
- `testRenameComponent` — создаёт компонент, вызывает `saveComponent()` с новым name, проверяет старый файл удалён, новый существует
- `testListComponents` — создаёт 3 компонента, `listComponents()` возвращает 3 записи, отсортированные по имени

### src/test/kotlin/ru/circuitforge/project/BomRepositoryTest.kt
- `testLoadEmpty` — TempDir без bom.json, `load()` возвращает `BomDocument()` с пустыми items
- `testSaveAndLoad` — создаёт BomDocument с 2 элементами, сохраняет, загружает, проверяет поля
- `testInitFromComponents` — создаёт 2 компонента в projectDir/components, `initFromComponents()` возвращает 2 элемента с правильными refDes
- `testSerializationFormat` — сохраняет BomDocument, читает JSON напрямую, проверяет `schemaVersion = 1` и ключи

### src/test/kotlin/ru/circuitforge/project/ProjectRepositoryTest.kt
- `testCreateProject` — создаёт проект в TempDir, проверяет наличие папок components/nets/exports и файла project.cfproj
- `testInvalidName` — `create("", ...)` и `create("a/b", ...)` — оба бросают `IllegalArgumentException`
- `testScanProjects` — создаёт 2 проекта в TempDir, `scan()` возвращает 2 ProjectInfo, отсортированных по имени
