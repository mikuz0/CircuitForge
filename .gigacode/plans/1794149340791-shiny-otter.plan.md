# CircuitForge — Этап 3: Ref Prefix + Редактор ПЭ3 (BOM)

## 1. Архитектура

```
┌──────────────────────────────────────────────────────────────┐
│  BomWindow (ProjectAware)                                    │
│                                                              │
│  BorderPane                                                  │
│  ├── top:    Toolbar (Add Item | Duplicate | Delete)        │
│  ├── center: TableView<BomRow> (RefDes editable, Comment editable)
│  └── bottom: [Save] [Revert] | Status Label                 │
│                                                              │
│  BomDocument.kt  — @Serializable модели (BomDocument, BomItem)
│  BomRepository.kt — load/save bom.json + loadRows (обогащение)
│  BomWindow.kt    — UI + контроллер (замена заглушки)
│  BomApp.kt       — main() + Application
│                                                              │
│  Component.kt      — добавить refPrefix
│  ComponentsWindow  — добавить поле refPrefix в форму
```

**Потоки:**
- FX Application Thread — UI, TableView inline-редактирование
- ExecutorService (2 daemon) — I/O через Task (load/save/listComponents)
- onSucceeded/onFailed — обновление UI

**Хранилище:**
- `<project>/bom.json` — JSON, prettyPrint, ignoreUnknownKeys
- `schemaVersion: 1`, `items: [{number, refDes, componentSlug, comment}]`
- `BomRow` — обогащённая строка с `componentName` из ComponentRepository

### 3.3 BomDocument.kt — модели данных

```kotlin
@Serializable
data class BomDocument(
    val schemaVersion: Int = 1,
    val items: List<BomItem> = emptyList()

@Serializable
data class BomItem(
    val number: Int,
    val refDes: String,
    val componentSlug: String,
    val comment: String = ""
)

data class BomRow(
    val number: Int,
    val refDes: String,
    val componentSlug: String,
    val componentName: String,
    val comment: String

```

### 3.4 BomRepository.kt — репозиторий

```kotlin
object BomRepository {
    private const val BOM_FILE_NAME = "bom.json"
    private val json = Json { prettyPrint = true; ignoreUnknownKeys = true }

    /**
     * Loads bom.json. Returns empty BomDocument if file not found (does NOT create).
     */
    fun load(projectDir: Path): BomDocument

    /**
     * Saves BomDocument to bom.json.
     */
    fun save(projectDir: Path, bom: BomDocument)

    /**
     * Enriches BomDocument items with component names from ComponentRepository.
     * If component file not found — componentName = "<not found: slug>".
     */
    fun loadRows(projectDir: Path): List<BomRow>
}
```

**loadRows реализация:**
1. Вызвать `load(projectDir)` → BomDocument
2. Для каждого BomItem:
   - Попытаться `ComponentRepository.loadComponent(projectDir, item.componentSlug)`
   - Успех → `componentName = component.name`
   - Исключение → `componentName = "<not found: ${item.componentSlug}>"`
3. Вернуть список BomRow

### 3.5 BomWindow.kt — UI

**Layout — BorderPane:**
```
top:    HBox (toolbar)
        [Add Item…] [Duplicate] [Delete]  HBox(spacer)  Label "Project: <path>"
center: TableView<BomRow> (editable, sortable=false)
        Columns:
          # (number, read-only, 60px)
          RefDes (editable, 100px)
          Component (componentName, read-only)
          Comment (editable, grow)
bottom: HBox
        HBox(spacer)  [Save] [Revert]  Label "" (status)
```

**TableView columns:**
- `#` — `TextFieldTableCell.forTableColumn<Int>` (не редактируемый, но можно показать)
- `RefDes` — `TextFieldTableCell.forTableColumn<String>`, editable
- `Component` — `TextFieldTableCell`, editable=false
- `Comment` — `TextFieldTableCell.forTableColumn<String>`, editable

**Add Item… логика:**
1. Загрузить список компонентов через `ComponentRepository.listComponents(projectDir)` (Task)
2. Показать `ChoiceDialog<String>` с именами компонентов
3. При выборе:
   - Загрузить Component через `ComponentRepository.loadComponent(projectDir, slug)` (Task)
   - Взять `refPrefix` (может быть пустым)
   - Сканировать текущие items BomDocument → найти max number среди RefDes, начинающихся с `$prefix`
   - Генерировать RefDes = `$prefix${max+1}` (если prefix пустой → RefDes = "")
   - Добавить BomRow: `componentSlug = slug, comment = ""`

**Duplicate логика:**
1. Скопировать выбранную строку
2. Взять refPrefix из `componentSlug` выбранного компонента
3. Сгенерировать новый RefDes (max + 1 для этого префикса)
4. Скопировать comment

**Delete:**
- Удаляет выбранную строку

**Валидация при сохранении:**
- Все RefDes непустые
- Все RefDes уникальны
- Если ошибка → Alert, отмена сохранения

**Сохранение:**
- Перенумеровать `number` (1..N) в порядке строк
- Записать `BomDocument` через `BomRepository.save()`
- Обновить savedSnapshot, dirty = false, статус "Saved"

**Revert:**
- Перечитать bom.json через `BomRepository.loadRows()`
- Заменить таблицу, dirty = false

**Dirty tracking:**
- При openProject → snapshot = serializeForm()
- При любом изменении → dirty = true
- При переключении/закрытии → диалог Save/Discard/Cancel

**Standalone без проекта:**
- VBox с Label "Open a project to edit BOM" и кнопкой "Open project…"
- DirectoryChooser → проверка project.cfproj → openProject

**Горячие клавиши:**
- Ctrl+S — Save
- Ctrl+N — Add Item
- Ctrl+D — Duplicate
- Delete — удалить выбранную строку

### 3.6 BomApp.kt — standalone entry point

```kotlin
class BomApp : Application() { ... }

fun main(args: Array<String>) {
    val projectPath = if (args.isNotEmpty()) Path.of(args[0]) else null
    val launcher = object : Application() {
        override fun start(ps: Stage) {
            val window = BomWindow()
            if (projectPath != null && Files.exists(projectPath)) {
                if (Files.exists(projectPath.resolve("project.cfproj"))) {
                    window.openProject(projectPath)
                    ps.title = "CircuitForge — BOM — $projectPath"
                } else {
                    showNoProjectView(ps, window, projectPath)
                }
            } else {
                showNoProjectView(ps, window, null)
            }
            ps.show()
        }
    }
    Application.launch(launcher::class.java, *args)
}
```
