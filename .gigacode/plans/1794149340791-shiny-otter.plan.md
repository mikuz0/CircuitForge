## Новая проблема: BOM не находит компоненты

### Суть
В колонке "Компонент" отображается `<не найдено: {0}>` вместо имён компонентов.

### Причина
**BomWindow.resolveComponentName()** формирует путь без расширения `.cfcomp`:
```kotlin
val compPath = dir.resolve("components").resolve(slug)  // ← нет .cfcomp
```
Компоненты хранятся как `<slug>.cfcomp`, поэтому `Files.exists()` всегда false.

### Файл для исправления
- `src/main/kotlin/ru/circuitforge/ui/editor/BomWindow.kt` — метод `resolveComponentName()`

### Исправление
Добавить константу `CFCOMP_EXT` и использовать её при формировании пути:
```kotlin
private const val CFCOMP_EXT = ".cfcomp"

private fun resolveComponentName(slug: String): String {
    if (slug.isBlank()) return I18n.tr("bom.placeholder.not.found")
    projectPath?.let { dir ->
        val compPath = dir.resolve("components").resolve("${slug}$CFCOMP_EXT")  // ← добавлен .cfcomp
        if (Files.exists(compPath)) {
            try {
                val comp = ComponentRepository.load(compPath)
                return comp.name
            } catch (e: Exception) {
                logger.warn("Failed to load component $slug", e)
            }
        }
    }
    return I18n.tr("bom.placeholder.not.found.detail", slug)
}
```
