## Проблемы, требующие исправления

### 1. NetWindow.refreshMatrix() — пустые цепи не попадают в матрицу

**Причина:** `portRefs` собирается только из цепей с соединениями. Пустые цепи не создают колонок.

**Файл:** `src/main/kotlin/ru/circuitforge/ui/nets/NetWindow.kt`
**Метод:** `refreshMatrix()` (строка ~290)

**Было:**
```kotlin
private fun refreshMatrix() {
    if (nets.isEmpty()) { matrixTable.items.clear(); return }

    val bomItems = projectPath?.let { BomRepository.load(it).items } ?: emptyList()
    if (bomItems.isEmpty()) {
        matrixTable.items.clear()
        return
    }

    val portRefs = mutableSetOf<String>()
    nets.forEach { net -> net.connections.forEach { portRefs.add("${it.refDes}.${it.pinNumber}") } }
    val sortedPortRefs = portRefs.sorted()

    if (sortedPortRefs.isEmpty()) { matrixTable.items.clear(); return }
```

**Стало:**
```kotlin
private fun refreshMatrix() {
    if (nets.isEmpty()) { matrixTable.items.clear(); return }

    val bomItems = projectPath?.let { BomRepository.load(it).items } ?: emptyList()
    if (bomItems.isEmpty()) {
        matrixTable.items.clear()
        return
    }

    // Собираем ВСЕ portRefs из ВСЕХ цепей (включая пустые)
    val portRefs = mutableSetOf<String>()
    nets.forEach { net ->
        net.connections.forEach { portRefs.add("${it.refDes}.${it.pinNumber}") }
    }
    val sortedPortRefs = portRefs.sorted()

    // Если connections есть, но они не привязаны к BOM — всё равно строим матрицу
    if (sortedPortRefs.isEmpty()) {
        // Показываем все цепи, но без колонок
        matrixTable.items.clear()
        matrixTable.columns.clear()
        return
    }
```

**Файл:** `src/main/kotlin/ru/circuitforge/project/ComponentRepository.kt`

**Стало:**
```kotlin
fun saveComponent(projectDir: Path, originalSlug: String, name: String, description: String, refPrefix: String, ports: List<Port>): String {
    val componentsDir = projectDir.resolve("components")
    
    // Проверяем уникальность name (кроме текущего компонента)
    if (name.isNotBlank() && hasNameConflict(componentsDir, originalSlug, name)) {
        throw IllegalArgumentException("Component with name '$name' already exists")
    }

    // Проверяем, используется ли компонент в BOM или Nets
    val bomDoc = BomRepository.load(projectDir)

        }
    }) {
        throw IllegalArgumentException("Component is used in Nets. Remove it first.")
    }

    val newSlug = generateUniqueSlug(projectDir, name)
    ...
```

### 4. BomRepository.initFromComponents() — post-increment bug

**Причина:** `number = number++, refDes = prefix + number` — `number++` пост-инкремент, поэтому `number` увеличивается ДО вычисления `refDes`.

**Файл:** `src/main/kotlin/ru/circuitforge/project/BomRepository.kt`
**Метод:** `initFromComponents()` (строка ~90)

**Было:**
```kotlin
val items = mutableListOf<BomItem>()
var number = 1
try {
    Files.list(componentsDir).use { stream ->
        stream.filter { it.fileName.toString().endsWith(".cfcomp") }
            .forEach { compPath ->
                try {
                    val comp = ComponentRepository.load(compPath)
                    val slug = comp.slug.takeIf { it.isNotBlank() }
                        ?: compPath.fileName.toString().removeSuffix(".cfcomp")
                    items.add(BomItem(
                        number = number++,
                        refDes = comp.refPrefix + number,
                        componentSlug = slug,
                        comment = comp.description
                    ))
                } catch (e: Exception) {
                    logger.warn("Failed to load component from $compPath", e)
                }
            }
    }
}
```

**Стало:**
```kotlin
val items = mutableListOf<BomItem>()
var number = 1
try {
    Files.list(componentsDir).use { stream ->
        stream.filter { it.fileName.toString().endsWith(".cfcomp") }
            .forEach { compPath ->
                try {
                    val comp = ComponentRepository.load(compPath)
                    val slug = comp.slug.takeIf { it.isNotBlank() }
                        ?: compPath.fileName.toString().removeSuffix(".cfcomp")
                    val currentNumber = number++
                    items.add(BomItem(
                        number = currentNumber,
                        refDes = comp.refPrefix + currentNumber,
                        componentSlug = slug,
                        comment = comp.description
                    ))
                } catch (e: Exception) {
                    logger.warn("Failed to load component from $compPath", e)
                }
            }
    }
}
```
