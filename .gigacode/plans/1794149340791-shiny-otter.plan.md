# Исправление NetWindow.kt — редактор связей

## Причины багов

1. **addConnectionButton/deleteConnectionButton не работают** — `setOnAction` не установлен в `setupToolbar()`
2. **ListView не обновляется** — `netListView.items.setAll(netNames)` копирует элементы один раз, а не привязывается
3. **refreshMatrix() не вызывается** — матрица не перестраивается после изменений
4. **markDirty() пустой** — `private fun markDirty() {}` — ничего не делает
5. **Нет защиты от потери данных** — нет `setOnCloseRequest`
6. **openProject не вызывает refreshMatrix()** — начальная матрица не строится

### 2. Добавить метод showCloseConfirmation()

```kotlin
/** Диалог подтверждения закрытия при несохранённых изменениях. */
private fun showCloseConfirmation() {
    val alert = Alert(Alert.AlertType.CONFIRMATION)
    alert.title = I18n.tr("bom.alert.unsaved")
    alert.headerText = I18n.tr("bom.alert.unsaved.header")
    alert.contentText = I18n.tr("bom.alert.unsaved.text")
    
    val result = alert.showAndWait()
    when {
        result.orElse(ButtonType.CANCEL) == ButtonType.YES -> {
            saveNets()
            if (!isDirty()) stage.close()
        }
        result.orElse(ButtonType.CANCEL) == ButtonType.NO -> stage.close()
    }
}
```

## Верификация

```bash
./gradlew clean build && ./gradlew run
```

1. Открыть проект с цепями → ListView показывает имена цепей
2. Выбрать цепь → таблица соединений обновляется
3. Добавить цепь → сразу появляется в ListView + обновляется матрица
4. Добавить соединение → сразу появляется в таблице + обновляется матрица
5. Удалить цепь/соединение → сразу удаляется + обновляется матрица
6. Изменить данные и закрыть окно → появляется диалог Save/Discard/Cancel
7. Нажать "Отменить" → dirty сбрасывается, статус очищается
