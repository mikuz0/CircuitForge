# План: Модуль «Редактор связей» (NetWindow)

## Обзор
Реализация полноценного редактора связей с хранением в nets.json. Гибридный UI: список + матрица через TabPane.

## Файлы для создания

### 1. src/main/kotlin/ru/circuitforge/project/NetDocument.kt
Data-классы:
- `NetConnection(val refDes: String, val pinNumber: String)`
- `Net(val name: String, val connections: List<NetConnection> = emptyList())`
- `NetDocument(val schemaVersion: Int = 1, val nets: List<Net> = emptyList())`
- Все `@Serializable`

### 2. src/main/kotlin/ru/circuitforge/project/NetRepository.kt
Object-репозиторий по аналогии с BomRepository:
- `load(projectPath: Path): NetDocument` — пустой, если файла нет
- `save(projectPath: Path, doc: NetDocument)` — с валидацией
- `validate(doc: NetDocument, projectPath: Path): List<String>` — возвращает список ошибок:
  - уникальность имён цепей
  - все refDes существуют в bom.json
  - все pinNumber существуют в соответствующем компоненте
- `exportToCsv(projectPath: Path, outputPath: Path)` — CSV-матрица (строки=цепи, колонки=порты)

### 3. src/main/kotlin/ru/circuitforge/ui/nets/NetWindow.kt
Полноценный редактор (замена заглушки):

**Layout (BorderPane):**
- Top: Toolbar [Add Net] [Delete Net] [Export CSV] + Project path label
- Center: TabPane
  - Вкладка "Список связей": SplitPane
    - Слева: ListView<Net> (имена цепей)
    - Справа: VBox → Label + TableView<NetConnection> (RefDes, PinNumber) + [Add Connection] [Delete Connection]
  - Вкладка "Матрица": ScrollPane → TableView<NetMatrixRow> (динамические колонки PortRef)
    - Ячейки — CheckBox
    - Клик обновляет модель и помечает dirty
- Bottom: [Save] [Revert] + Status Label

**Логика:**
- Add Net: TextInputDialog → новая цепь
- Add Connection: кастомный Dialog (ComboBox refDes из bom.json + ComboBox pinNumber из компонента)
- Dirty tracking: serializeCurrentState() vs savedSnapshot
- Защита от потери данных при закрытии
- I/O через Task на daemon ExecutorService
