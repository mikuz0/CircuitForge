# План: Исправление исчезновения компонентов со схемы

## Проблема

После последнего исправления компоненты (SVG-символы) исчезли со схемы. Видны только подписи (R1, C1, DD1) и порты (синие кружки).

## Корень проблемы

`SymbolLibrary.loadSymbol()` проверяет `definition != null` (теперь true, т.к. конфиг загружен из resources fallback), но SVG-файл ищется в `projectDir/symbols/` и не найден. Возвращается пустой `createFallbackPane(symbolType)` без SVG.

## Решение

**Файл:** `src/main/kotlin/ru/circuitforge/ui/schematic/symbols/SymbolLibrary.kt`

В `loadSymbol()` добавить проверку существования файла:

```kotlin
private fun loadSymbol(symbolType: String): Pane {
    val definition = config.symbols[symbolType]
    
    return if (definition != null) {
        val svgFile = symbolsDir.resolve(definition.file)
        if (Files.exists(svgFile)) {
            loadSymbolFromFile(symbolType, svgFile, definition.width, definition.height)
        } else {
            // SVG не найден в проекте — fallback на resources
            logger.info("SVG file not found: $svgFile, loading from resources")
            val resourcePane = loadSymbolFromResources(symbolType)
                ?: createFallbackPane(symbolType)
        }
    } else {
        val resourcePane = loadSymbolFromResources(symbolType)
            ?: createFallbackPane(symbolType)
    }
}
```

## Верификация

1. `./gradlew build` — компиляция без ошибок
2. Открыть `proba` — компоненты (резисторы, конденсаторы) должны отображаться на схеме
3. Порты (синие кружки) должны быть на выводах компонентов
