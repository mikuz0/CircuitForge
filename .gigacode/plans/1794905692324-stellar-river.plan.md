# План: Рефакторинг SchematicWindow.kt

## Цель
Разделить большой файл на 3 модуля по ответственности.

## Разделение

| Файл | Строки | Содержание |
|------|--------|-----------|
| `SchematicWindow.kt` | ~150 | Состояние, layout, openProject, save/revert |
| `ComponentRenderer.kt` | ~150 | Отрисовка компонентов (3 типа) |
| `WireEditor.kt` | ~200 | Редактирование линий, точки, обработчики мыши |

- `drawLines()`
- `drawGrid()`

- Поля `tempClickPoint`, `draggingPoint`, `dragPointOffsetX/Y`, `selectedPoint`
