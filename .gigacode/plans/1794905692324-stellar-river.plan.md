- **тестах** (`BomRepositoryTest.kt`) — конструктор и свойства

- **UI** (`NetWindow.kt`, `ComponentsWindow.kt`) — доступ к `componentSlug`

## Шаг 3: Обновить `BomRepository.loadRows` для заполнения `componentSlug`

**Файл**: `src/main/kotlin/ru/circuitforge/project/BomRepository.kt`

В `loadRows` добавить разрешение slug из файлов компонентов (если в BOM он пустой):

```kotlin
fun loadRows(projectPath: Path): List<BomRow> {
    val bomDoc = load(projectPath)
    val rows = mutableListOf<BomRow>()

    bomDoc.items.forEach { item ->
        var compName = "<not found>"
        var prefix = "?"
        var slug = item.componentSlug
        try {
            val comp = ComponentRepository.loadComponentById(projectPath, item.componentId)
            if (comp != null) {
                compName = comp.name
                prefix = comp.refPrefix
                if (slug.isBlank()) {
                    val componentsDir = projectPath.resolve("components")
                    if (Files.exists(componentsDir)) {
                        Files.list(componentsDir).use { stream ->
                            stream.filter { it.fileName.toString().endsWith(".cfcomp") }
                                .forEach { path ->
                                    try {
                                        val loadedComp = ComponentRepository.load(path)
                                        if (loadedComp.id == item.componentId) {
                                            slug = path.fileName.toString().removeSuffix(".cfcomp")
                                        }
                                    } catch (e: Exception) { /* skip */ }
                                }
                        }
                    }
                }
            }
        } catch (e: Exception) {
            logger.warn("Failed to load component by id: ${item.componentId}", e)
        }

        rows.add(BomRow(
            bomnetId = item.bomnetId,
            number = item.number,
            refDes = item.refDes,
            componentId = item.componentId,
            componentSlug = slug,
            componentName = compName,
            comment = item.comment,
            refPrefix = prefix
        ))
    }
    return rows
}
```

## Шаг 4: Добавить `initFromComponents` в `BomRepository`

**Файл**: `src/main/kotlin/ru/circuitforge/project/BomRepository.kt`

Добавить метод после `save`:

```kotlin
fun initFromComponents(projectPath: Path): BomDocument {
    val componentsDir = projectPath.resolve("components")
    if (!Files.exists(componentsDir)) {
        logger.warn("No components directory found at $componentsDir")
        return BomDocument()
    }

    val items = mutableListOf<BomItem>()
    try {
        Files.list(componentsDir).use { stream ->
            stream.filter { it.fileName.toString().endsWith(".cfcomp") }
                .sorted()
                .forEach { path ->
                    try {
                        val comp = ComponentRepository.load(path)
                        val slug = path.fileName.toString().removeSuffix(".cfcomp")
                        val prefix = comp.refPrefix.uppercase()
                        val refDes = if (prefix.isNotBlank()) "$prefix${items.size + 1}" else "COMP${items.size + 1}"
                        items.add(
                            BomItem(
                                number = items.size + 1,
                                refDes = refDes,
                                componentId = comp.id,
                                componentSlug = slug,
                                comment = comp.description
                            )
                        )
                    } catch (e: Exception) {
                        logger.warn("Failed to load component from $path, skipping", e)
                    }
                }
        }
    } catch (e: Exception) {
        logger.error("Failed to scan components directory: $componentsDir", e)
    }

    return BomDocument(schemaVersion = 1, items = items)
}
```

**Почему**: Тест `testInitFromComponents` вызывает этот метод.

## Новая задача: Исправить сохранение комментария в BOM

### Проблема
Колонка "Комментарий" в `BomWindow` использует стандартный `TextFieldTableCell<BomRow, String>()`, который в текущей конфигурации не вызывает `commitEdit` при нажатии Enter. Значение вводится, но `onEditCommit` не срабатывает.

### Решение
Заменить стандартный `TextFieldTableCell` на кастомный `cellFactory` с явной обработкой `TextField.setOnAction { commitEdit(textField.text) }` — по рабочему паттерну из `ComponentsWindow`.

**Файл**: `src/main/kotlin/ru/circuitforge/ui/editor/BomWindow.kt`

**Заменить блок** (строки ~110-117, колонка Comment):
```kotlin
// Колонка Comment (редактируемая)
val commentCol = TableColumn<BomRow, String>("Комментарий")
commentCol.setCellValueFactory { javafx.beans.property.SimpleStringProperty(it.value.comment) }
commentCol.prefWidth = 300.0
commentCol.cellFactory = javafx.util.Callback { _ -> TextFieldTableCell<BomRow, String>() }
commentCol.setOnEditCommit { event ->
    val row = event.rowValue
    val newComment = event.newValue ?: ""
    val index = bomRows.indexOf(row)
    if (index >= 0) {
        bomRows[index] = row.copy(comment = newComment)
        markDirty()
    }
}
```

**На**:
```kotlin
// Колонка Comment (редактируемая)

commentCol.setCellValueFactory { javafx.beans.property.SimpleStringProperty(it.value.comment) }

    object : TableCell<BomRow, String>() {
        private val textField = TextField()
        init {
            textField.setOnAction {
                commitEdit(textField.text)
            }
            textField.focusedProperty().addListener { _, _, isFocused ->
                if (!isFocused) commitEdit(textField.text)
            }
        }
        override fun startEdit() {
            super.startEdit()
            textField.text = item ?: ""
            graphic = textField
            text = null
            textField.requestFocus()
            textField.selectAll()
        }
        override fun cancelEdit() {
            super.cancelEdit()
            text = item
            graphic = null
        }
        override fun updateItem(item: String?, empty: Boolean) {
            super.updateItem(item, empty)
            if (empty || item == null) {
                text = null
                graphic = null
            } else if (isEditing) {
                textField.text = item
                graphic = textField
                text = null
            } else {
                text = item
                graphic = null
            }
        }
    }
}
commentCol.setOnEditCommit { event ->
    val row = event.rowValue
    val newComment = event.newValue?.trim() ?: ""
    val index = bomRows.indexOf(row)
    if (index >= 0) {
        bomRows[index] = row.copy(comment = newComment)
        markDirty()
    }
}
```

## Новая задача: Валидация префикса в колонке "Поз. обозначение"

### Проблема
Колонка "Поз. обозначение" (RefDes) принимает любое значение без проверки. Нужно запретить изменение префикса — разрешено менять только порядковый номер. Источник истины — `refPrefix` в `BomRow` (берётся из компонента).

**Пример**: `DD1` → `DD65` ✅, `DD1` → `DA1` ❌ (префикс компонента — `DD`).

### Решение
В `refDesCol.setOnEditCommit` добавить валидацию:
1. Извлечь префикс из нового refDes (все символы кроме финальных цифр) через Regex `^(.*[^0-9])([0-9]+)$`
2. Сравнить с `row.refPrefix`
3. Если не совпадает — откатить (`tableView.refresh()`), показать `UiUtils.errorAlert`
4. Если совпадает — сохранить
5. Дополнительно: проверить уникальность refDes

**Файл**: `src/main/kotlin/ru/circuitforge/ui/editor/BomWindow.kt`

**Заменить блок** (строки 92-105):
```kotlin
        // Колонка RefDes (редактируемая)
        val refDesCol = TableColumn<BomRow, String>("Поз. обозначение")
        refDesCol.setCellValueFactory { javafx.beans.property.SimpleStringProperty(it.value.refDes) }
        refDesCol.prefWidth = 150.0
        refDesCol.cellFactory = javafx.util.Callback { _ -> TextFieldTableCell<BomRow, String>() }
        refDesCol.setOnEditCommit { event ->
            val row = event.rowValue
            val newRefDes = event.newValue?.trim() ?: ""
            if (newRefDes.isNotBlank()) {
                val index = bomRows.indexOf(row)
                if (index >= 0) {
                    bomRows[index] = row.copy(refDes = newRefDes)
                    markDirty()
                }
            } else {
                tableView.refresh()
            }
        }
```

**На**:
```kotlin
        // Колонка RefDes (редактируемая)
        val refDesCol = TableColumn<BomRow, String>("Поз. обозначение")
        refDesCol.setCellValueFactory { javafx.beans.property.SimpleStringProperty(it.value.refDes) }
        refDesCol.prefWidth = 150.0
        refDesCol.cellFactory = javafx.util.Callback { _ -> TextFieldTableCell<BomRow, String>() }
        refDesCol.setOnEditCommit { event ->
            val row = event.rowValue
            val newRefDes = event.newValue?.trim() ?: ""
            if (newRefDes.isBlank()) {
                tableView.refresh()
                return@setOnEditCommit
            }

            // Валидация префикса: извлечь префикс (все символы кроме финальных цифр)
            val prefixRegex = Regex("^(.*[^0-9])([0-9]+)$")
            val matchResult = prefixRegex.matchEntire(newRefDes)
            if (matchResult == null) {
                // Не удалось извлечь префикс — значение не соответствует формату
                if (row.refPrefix.isNotBlank()) {
                    UiUtils.errorAlert(
                        I18n.tr("common.alert.error") ?: "Ошибка",
                        "Поз. обозначение должно содержать префикс '" + row.refPrefix + "' и номер."
                    )
                    tableView.refresh()
                    return@setOnEditCommit
                }
            } else {
                val extractedPrefix = matchResult.groupValues[1]
                if (extractedPrefix != row.refPrefix) {
                    UiUtils.errorAlert(
                        I18n.tr("common.alert.error") ?: "Ошибка",
                        "Префикс должен быть '" + row.refPrefix + "', а не '" + extractedPrefix + "'."
                    )
                    tableView.refresh()
                    return@setOnEditCommit
                }
            }

            // Уникальность RefDes
            if (bomRows.map { it.refDes }.filter { it != row.refDes }.contains(newRefDes)) {
                UiUtils.errorAlert(
                    I18n.tr("common.alert.error") ?: "Ошибка",
                    "Поз. обозначение '" + newRefDes + "' уже существует."
                )
                tableView.refresh()
                return@setOnEditCommit
            }

            val index = bomRows.indexOf(row)
            if (index >= 0) {
                bomRows[index] = row.copy(refDes = newRefDes)
                markDirty()
            }
        }
```

**Верификация**: `./gradlew clean build` → `BUILD SUCCESSFUL`. Вручную: `DD1` → `DD65` ✅, `DD1` → `DA1` ❌ с alert, `DD1` → `DD1` (дубликат) ❌.
